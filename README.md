# Clube de Assinatura

Projeto estático desenvolvido durante a Formação Fullstack da Rocketseat, no módulo de HTML e CSS. É o último projeto do módulo, focado em praticar animações e transições com CSS.

## Objetivo

Treinar e consolidar os seguintes conceitos:

- **Animações CSS** (`animation`, `@keyframes`)
- **Transições suaves** em estados interativos (hover, focus, active)
- **Organização de estilos** por módulos de página
- **Semântica em HTML** e estruturação de layout

## Tecnologias e Ferramentas

- **HTML5**
- **CSS3** (transitions, animations)
- Navegador moderno e, opcionalmente, **Live Server** no VS Code

## Como Executar Localmente

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` diretamente no navegador.
3. (Opcional) Use a extensão Live Server do VS Code para recarregamento automático.

## Recursos e Destaques

- **Animações e microinterações** para enriquecer a experiência do usuário
- **Transições** aplicadas a botões, links e elementos de interface
- **Estilos modulares** por seção: `hero`, `pricing`, `kit-monthly`, `surprise` e `footer`
- **Utilitários CSS** concentrados em `styles/utility.css`
- **Assets organizados** em `assets/` (ícones, imagens e vetores)
